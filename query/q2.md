# 题目2：基于FFT的正则匹配算法

## 题目要求

### 背景知识
快速傅里叶变换（FFT）是一种高效的算法，用于计算离散傅里叶变换（DFT）及其逆变换。虽然不需要深入理解其数学原理，但需要了解其输入输出特性：
- **输入**：两个长度为n的多项式系数向量
- **输出**：两个多项式的乘积系数向量
- **时间复杂度**：O(n log n)

### 问题描述
利用快速傅里叶变换（FFT）算法，实现一个详细的正则匹配过程：

**输入：**
- 主串 S（长度为 n）
- 模式串 P（长度为 m，只包含字母和通配符 ?，其中 ? 可以匹配任意单个字符）

**输出：**
- P 在 S 中的所有匹配位置的查找结果

**约束条件：**
- n >> m（主串长度远大于模式串长度）
- 通配符 ? 可以匹配任意单个字符

## 解题思路

### 1. 问题转化

将字符串匹配问题转化为多项式乘法问题：

1. **字符编码**：将字符转换为数值
   - 普通字母：使用其ASCII值或自定义编码
   - 通配符 ?：使用特殊值（如0或-1）

2. **多项式表示**：
   - 主串S：$S(x) = s_0 + s_1x + s_2x^2 + ... + s_{n-1}x^{n-1}$
   - 模式串P：$P(x) = p_0 + p_1x + p_2x^2 + ... + p_{m-1}x^{m-1}$

3. **匹配条件**：在位置i匹配当且仅当 $S[i:i+m-1]$ 与 $P[0:m-1]$ 匹配

### 2. FFT算法设计

#### 2.1 基本思路
使用FFT计算多项式乘积，通过乘积结果判断匹配位置：

```
Algorithm FFT_StringMatching(S, P):
    n = length(S)
    m = length(P)
    
    // 1. 将字符串转换为多项式系数
    S_coeff = encode_string(S)
    P_coeff = encode_string(P)
    
    // 2. 使用FFT计算多项式乘积
    result = FFT_multiply(S_coeff, P_coeff)
    
    // 3. 分析结果找出匹配位置
    matches = find_matches(result, n, m)
    
    return matches
```

#### 2.2 字符编码策略
```python
def encode_character(char):
    if char == '?':
        return 0  # 通配符编码为0
    else:
        return ord(char) - ord('a') + 1  # 字母编码为1-26
```

#### 2.3 匹配判断
对于位置i，如果满足以下条件则认为匹配：
- 对于所有j (0 ≤ j < m)：
  - 如果P[j] ≠ '?'，则S[i+j] = P[j]
  - 如果P[j] = '?'，则S[i+j]可以是任意字符

### 3. 详细算法实现

#### 3.1 多项式乘法方法
```python
def FFT_string_matching(S, P):
    n, m = len(S), len(P)
    
    # 补零到2的幂次
    size = 1
    while size < n + m - 1:
        size *= 2
    
    # 编码字符串
    S_encoded = [encode_char(c) for c in S] + [0] * (size - n)
    P_encoded = [encode_char(c) for c in P] + [0] * (size - m)
    
    # 使用FFT计算乘积
    S_fft = FFT(S_encoded)
    P_fft = FFT(P_encoded)
    
    # 逐点相乘
    product_fft = [S_fft[i] * P_fft[i] for i in range(size)]
    
    # 逆FFT得到结果
    result = IFFT(product_fft)
    
    return result
```

#### 3.2 匹配位置提取
```python
def extract_matches(result, n, m):
    matches = []
    for i in range(n - m + 1):
```

### 4. 时间复杂度分析

#### 4.1 主要步骤分析
1. **字符串编码**：O(n + m)
2. **FFT计算**：O(n log n)（假设n >> m，使用n作为主要参数）
3. **逆FFT计算**：O(n log n)
4. **匹配位置提取**：O(n)

#### 4.2 总体复杂度
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

#### 4.3 复杂度证明
- FFT和IFFT的时间复杂度都是O(n log n)
- 字符串编码和匹配提取都是O(n)
- 由于n >> m，主要复杂度由FFT决定
- 因此总时间复杂度为O(n log n)

### 5. 算法优势

1. **理论优势**：
   - 时间复杂度O(n log n)，优于传统的O(nm)算法
   - 特别适合长文本匹配场景

2. **实际优势**：
   - 可以利用现有的FFT库实现
   - 并行化友好
   - 数值稳定性好

### 6. 实现注意事项

1. **数值精度**：FFT涉及复数运算，需要注意数值精度
2. **边界处理**：需要正确处理字符串边界
3. **通配符处理**：通配符的编码需要特殊处理
4. **内存管理**：大字符串可能需要考虑内存优化

## 总结

基于FFT的正则匹配算法通过将字符串匹配问题转化为多项式乘法问题，实现了O(n log n)的时间复杂度。该算法特别适合处理长文本的模式匹配，是传统字符串匹配算法的重要改进。
