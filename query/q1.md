# 题目1：反向对称矩阵算法设计

## 问题描述

设 $A$ 为一 $n \times n$ 矩阵。若 $A$ 的每一条从左上到右下的对角线（即所有满足 $i-j$ 相同的位置）上的元素都相等，则称 $A$ 为**反向对称矩阵**。

### 矩阵结构示例（n=5）

```
a₄  a₃  a₂  a₁  a₀
a₅  a₄  a₃  a₂  a₁
a₆  a₅  a₄  a₃  a₂
a₇  a₆  a₅  a₄  a₃
a₈  a₇  a₆  a₅  a₄
```

其中每个元素 $A_{i,j} = a_{n-1+i-j}$

## 算法设计

### 压缩表示
反向对称矩阵 $A$ 可以用长度为 $2n-1$ 的向量 $a = [a_0, a_1, ..., a_{2n-2}]$ 来表示，其中：
- $a_k$ 表示满足 $i-j = k-(n-1)$ 的所有位置 $(i,j)$ 的元素值

### 矩阵-向量乘积算法

**输入：**
- 压缩向量 $a = [a_0, a_1, ..., a_{2n-2}]$（长度为 $2n-1$）
- 向量 $v = [v_0, v_1, ..., v_{n-1}]$（长度为 $n$）

**输出：**
- 向量 $u = A \cdot v$，其中 $u_i = \sum_{j=0}^{n-1} A_{i,j} \cdot v_j$

**伪代码：**
```
Algorithm MatrixVectorProduct(a, v, n):
    // 初始化结果向量
    u = [0, 0, ..., 0]  // 长度为n的零向量
    
    // 计算矩阵-向量乘积
    for i = 0 to n-1:
        for j = 0 to n-1:
            // 计算元素A[i,j]在压缩向量中的索引
            k = n-1 + i - j
            // 累加乘积
            u[i] = u[i] + a[k] * v[j]
    
    return u
```

### 优化算法

注意到对于每个 $i$，我们需要计算 $u_i = \sum_{j=0}^{n-1} a_{n-1+i-j} \cdot v_j$

可以进一步优化：

```
Algorithm OptimizedMatrixVectorProduct(a, v, n):
    u = [0, 0, ..., 0]  // 长度为n的零向量
    
    for i = 0 to n-1:
        for j = 0 to n-1:
            k = n-1 + i - j
            u[i] = u[i] + a[k] * v[j]
    
    return u
```

## 复杂度分析

### 时间复杂度

**基本算法：**
- 外层循环：$O(n)$
- 内层循环：$O(n)$
- 总时间复杂度：$O(n^2)$

**空间复杂度：**
- 额外空间：$O(n)$（用于存储结果向量 $u$）
- 总空间复杂度：$O(n)$

### 证明时间复杂度上界

1. **算法执行步骤分析：**
   - 初始化结果向量：$O(n)$
   - 双重循环：外层 $n$ 次，内层每次 $n$ 次
   - 每次内层循环中的操作（索引计算、乘法、加法）：$O(1)$

2. **总操作数：**
   - 循环体执行次数：$n \times n = n^2$
   - 每次循环的操作：$O(1)$
   - 总时间复杂度：$O(n^2)$

3. **上界证明：**
   - 存在常数 $c > 0$，使得对于所有 $n \geq n_0$，算法执行时间 $T(n) \leq c \cdot n^2$
   - 这满足 $O(n^2)$ 的定义

### 最优性分析

对于一般的 $n \times n$ 矩阵与 $n$ 维向量的乘积，$O(n^2)$ 是理论最优的时间复杂度，因为：
- 输出向量有 $n$ 个元素
- 每个元素需要 $n$ 次乘法和 $n-1$ 次加法
- 总操作数：$n \times (n + n-1) = O(n^2)$

因此，我们的算法达到了最优的时间复杂度。

## 总结

1. **算法设计：** 设计了时间复杂度为 $O(n^2)$ 的矩阵-向量乘积算法
2. **空间复杂度：** $O(n)$
3. **最优性：** 算法达到了理论最优的时间复杂度
4. **实现：** 算法简单高效，易于实现

该算法充分利用了反向对称矩阵的特殊结构，通过压缩表示避免了存储完整的 $n^2$ 个矩阵元素，同时保持了最优的计算效率。
