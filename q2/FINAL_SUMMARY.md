## 🚀 算法特性

### 核心功能
- **FFT字符串匹配**：使用快速傅里叶变换进行字符串匹配
- **通配符支持**：支持 `?` 通配符匹配任意单个字符
- **完整匹配**：找到所有匹配位置
- **详细过程**：提供详细的匹配过程分析

### 优化策略
1. **迭代式FFT** - 消除递归调用开销
2. **内存池管理** - 减少GC压力和内存分配
3. **自适应策略** - 根据数据规模自动选择最优算法
4. **NumPy集成** - 利用高度优化的FFT库
5. **分块处理** - 支持超长字符串
6. **启发式预处理** - 快速排除不可能匹配

## 🔧 使用方法

### 基本使用
```python
from fft_string_matching import FFTStringMatcher

matcher = FFTStringMatcher()
matches = matcher.fft_string_matching("主串", "模式串")
```

### 通配符使用
```python
# 支持通配符 ? 匹配任意字符
matches = matcher.fft_string_matching("abcdef", "a?c?e")
```

### 详细模式
```python
# 获取详细的匹配过程
matches = matcher.fft_string_matching("主串", "模式串", verbose=True)
```
